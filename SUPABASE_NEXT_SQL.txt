BIBLE QUESTION JOURNAL — CLOUD SETUP FOLLOW-UP

Run this once in Supabase SQL Editor before using the cloud-connected PWA.

The original reading_progress table stores one row per user + book. The PWA also needs to remember which individual chapters have been completed, so add the chapter list and the last-reading marker:

ALTER TABLE public.reading_progress
  ADD COLUMN IF NOT EXISTS completed_chapters integer[] NOT NULL DEFAULT '{}';

ALTER TABLE public.reading_progress
  ADD COLUMN IF NOT EXISTS is_last boolean NOT NULL DEFAULT false;

CREATE INDEX IF NOT EXISTS reading_progress_last_idx
  ON public.reading_progress(user_id, is_last);
